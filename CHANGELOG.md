# Changelog

## 1.42.1

Всё, что накопилось с 1.26:

**Телефон**
- Вкладка «Терминал Мака» (`t`): обычная оболочка на Маке в своей tmux-сессии, не агент. Поле для команды, история, кнопки Esc / Tab / Ctrl-C и стрелки — удобно с телефона. Выключается `"web_shell": "off"`.
- Уведомления Web Push (стандартная библиотека Go, VAPID + aes128gcm): разрешения, меню, вопросы агентов, «нужен ты» от дирижёра и помощника. Раздел «Телефон» в настройках, тестовое уведомление.
- Установка на экран Домой: иконки, manifest с ключом, учёт выреза и строки состояния. Доступ — через `tailscale serve` (HTTPS в tailnet).

**Доска и карта**
- Доска вместо «Обзора»: колонки «Ждут тебя», «Ждут дирижёра», «Готово, проверь», «Работают», «В ожидании»; вопрос сессии и кнопки ответа прямо на карточке; неотвеченный вопрос через 10 минут переезжает в «Ждут тебя».
- Вид «Карта» (выбирается в настройках): дирижёр в центре, сверху ты, по овалу сессии, при многих — в шахматном порядке; лёгкая анимация линий на CSS.
- Быстрый просмотр справа: чат сессии, кнопки разрешений, ответ без перехода (Shift+Enter — новая строка, «Стоп» / Shift+Esc — прервать агента), скрепка и перетаскивание файлов.

**Статистика и ресурсы**
- Вкладка «Статистика» (`s`): дорожка на сессию по истории статусов, сколько агентов работало одновременно, сколько ждали тебя и дирижёра; 3 ч – неделя.
- Вкладка «Ресурсы» (`d`): сколько сессий в работе, лимиты, диск, места.

**Чат и сессии**
- Сессия как чат из журнала Claude Code: плашки инструментов, таблицы, живая строка «Работает · шаг · время»; ответ на разрешения и меню прямо в чате.
- Превью картинок и видео в чате, просмотр внутри оркестра; вложения (📎, ⌘V, перетаскивание).
- Панель «Обновления»: разбор обновлений в тестировании по git (чат анонсов и трекер задаются в config.json).
- `cs ctl send` проверяет, что текст дошёл; забытые окна подтверждения не блокируют очередь; сторож зависших сессий и перезапуск VPN-клиента; прокси для Claude через HTTPS_PROXY / PAC.
