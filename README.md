# orchestraByVitalik

Оркестр сессий Claude Code для QA. Основан на [Claude Squad](https://github.com/smtg-ai/claude-squad) (AGPL-3.0), доработан
под работу QA с несколькими сессиями Claude Code: все сессии в одном терминале,
статусы и стадии задач, ответ без захода в сессию, сон для экономии памяти и
сессия-дирижёр, которая ведёт рутину проверок. Оригинальный README — `docs/UPSTREAM_README.md`.

## Установка (macOS)

Нужны: macOS, [Homebrew](https://brew.sh) и Claude Code (поставлен, `claude` запускается, вход выполнен).
Остальное (tmux, Go, инструменты разработчика Apple) установщик поставит или подскажет сам.

```bash
git clone https://github.com/<you>/orchestraByVitalik ~/claude-squad-qa && cd ~/claude-squad-qa
./install-mac.sh
```

Установщик спросит одно — папку репозитория, где будут работать сессии (например, `~/work/my-app`), и сделает остальное:
соберёт Squad в `~/bin`, разложит дирижёра и помощника в `~/.claude-squad` со своими путями,
по желанию добавит уведомления в Claude Code, соберёт приложение «Оркестр», запустит Squad в фоне
и создаст дирижёра и помощника. Дальше — `open ~/Applications/Orchestra.app`.

**Профиль команды.** Установщик спросит профиль. «Общий» — дирижёр и помощник без привязки к чьей-то
команде: подходит всем. Профили лежат в `contrib/profiles/<имя>/`: `profile.json` (название и
настройки Squad — чат для утреннего отчёта `brief_chat`, доска задач `team_board`, `vpn_check`) и
папки `conductor/`, `assistant/` с `profile.md` (продукт, чаты, договорённости), скиллами и
правилами, которые ложатся поверх общих. Свой профиль — скопируй `contrib/profiles/example` в папку со своим названием и опиши в нём команду.
Сменить профиль — запусти `./install-mac.sh` ещё раз.

**Обновление:** `cd ~/claude-squad-qa && git pull && ./install-mac.sh` — твои правила дирижёра
(`rules.md`) и настройки остаются, Squad перезапускается сам, сессии Claude при этом работают.

Пути — в `~/.claude-squad/sq.env` (`SQ_DIR` — папка сессий, `SQ_REPO` — эта репа). Ручная сборка:
`go build -o ~/bin/cs.new . && mv ~/bin/cs.new ~/bin/cs` (атомарно, чтобы работающие `cs ctl` не ловили «permission denied»).

### Уведомления (install-mac.sh предлагает добавить их сам; вручную — так)
```bash
cp contrib/claude-notify ~/bin/ && chmod +x ~/bin/claude-notify
```
В `~/.claude/settings.json` добавь хуки:
```json
{"hooks": {
  "Stop": [{"matcher": "", "hooks": [{"type": "command", "command": "$HOME/bin/claude-notify stop"}]}],
  "Notification": [{"matcher": "permission_prompt", "hooks": [{"type": "command", "command": "$HOME/bin/claude-notify notify"}]}]
}}
```
С `brew install terminal-notifier` клик по уведомлению открывает эту сессию в Squad
на весь экран (`cs ctl focus`), а если Squad закрыт — запускает его в новом окне
терминала. Новое уведомление сессии заменяет её старое.
В заголовке уведомления — цвет и номер сессии Squad. Хук же запоминает id
разговора, чтобы после сна сессия поднималась с тем же разговором.

## Клавиши

| Клавиша | Что делает |
|---|---|
| `n` / `N` | новая сессия / с выбором ветки (ветка с готовым worktree — сессия откроется в нём) |
| `Enter`, `Ctrl+Q` | зайти в сессию / выйти обратно |
| `i` | написать в сессию, не заходя: видна переписка, черновик, Tab — подсказка Claude |
| `v` | обзор всех сессий |
| `s` | сводка по всем задачам в буфер |
| `C` `e` `R` | цвет, описание, переименовать |
| `r` | запустить спящую/остановленную сессию |
| `D` | закрыть сессию (папка и ветка остаются) |

Статусы: «в работе», «ждёт тебя», «нужно разрешение», «прерван», «нет сети» и
голубой «в ожидании · таймер / пайплайн / опрос / фоновая задача» — агент сам чего-то
ждёт (sleep, CI, фоновую команду); такие сессии не будят дирижёра и не засыпают.
Сессии сортируются по срочности. Сессия, которая ждёт дольше 2 часов, засыпает
(процесс Claude закрывается, память освобождается); `r` возвращает тот же разговор.
Настройки в `~/.claude-squad/config.json`: `auto_pause_minutes` (−1 — выкл),
`conductor_interval_minutes` (−1 — выкл).

### Обрывы VPN
```json
"vpn_check": ["git.example.com:443"]
```
Хост, доступный только через VPN. Squad проверяет его раз в 10 секунд. Пока VPN
лежит, Squad ничего не трогает и не будит дирижёра. Когда сеть вернётся (через 45 секунд, чтобы всё
успело переподключиться само):
- сессию, которая так и висит на вызове MCP с момента обрыва, Squad прерывает (Esc),
  перезапускает с тем же разговором (MCP подключаются заново) и просит продолжить;
- сессию, которая остановилась с ошибкой сети, просит продолжить;
- долгую локальную работу (тесты, сборка), черновики, запросы разрешений и сессию,
  в которой ты сейчас, не трогает.
Итог приходит уведомлением. Ещё Squad ограничивает один вызов MCP 10 минутами
(`mcp_tool_timeout_seconds`, −1 — лимит Claude Code), чтобы он не висел вечно.

Папки, которые ты подключаешь (свои worktree, площадки), Squad никогда не удаляет,
ничего в них не коммитит и не пушит.

## Лимиты, отчёты, уборка — без токенов

- В заголовке списка — сколько лимита съедено: `лимит 5ч 63% · нед 22%` (и `VPN ✗`,
  когда VPN лежит), у каждой сессии — сколько токенов она съела сегодня. При 70%
  приходит уведомление, с 85% дирижёр просыпается в 3 раза реже. Проценты появятся
  после калибровки: открой `/usage` в Claude и передай цифры —
  `cs usage --calibrate 5h=40 --calibrate week=25`. `cs usage` — расход по сессиям.
- `w` — что было, пока тебя не было: кто что закончил, кто ждёт, что сделал
  дирижёр, обрывы VPN, токены. Сам показывается при первом запуске за день.
- `cs stats` — неделя: сколько агенты работали, сколько ждали тебя, дольше всего
  ждавшие, токены по дням.
- `O` — открыть QA-отчёт (`report.html`) выбранной сессии, `f` — её папку.
- `cs cleanup` — заброшенные площадки и worktree с размером и пустые папки.
  Ничего не удаляет.
- `cs ctl capacity` — есть ли ресурс взять ещё задачу (места из
  `max_active_sessions`, по умолчанию 6, и лимиты). По будням 10–19 Squad сам
  напомнит, когда ресурс есть (не чаще раза в 2 часа; `capacity_notify_off: true` — выкл).

## Питомец в обзоре

В правом нижнем углу обзора (`v`) живёт рыжая тян (одноцветный рисунок точками Брайля,
анимированный). Её настроение — по твоей «плотности», 12 ступеней: 0 ч — рыдает, 1–5 — от «очень
грустно» до «почти норм», 6 (цель) — довольна, 8 — радуется, 10 — очень радуется, 13 — в восторге,
17 — сияет, 21+ — очень-очень радостно. Снизу подпись: «плотность 5 ч · почти норм», под ней «до цели 1 ч · этот час ✓» —
зелёная галочка, если в текущем часе уже есть твой коммит (✗ — ещё нет).
- плотность берётся из `"density_command"` (раз в 10 минут). Для плотности коммитов:
  `"density_command": "~/bin/commit-density"` — сколько часов сегодня были с твоим коммитом
  (репы в `~/devRepo`, учитываются и worktree'ы Squad). Без команды Squad оценивает сам по логам
  Claude Code: сколько агентов в среднем работали параллельно. `cs density` — что сейчас считается;
- `cs density 10,4` — задать вручную на сегодня (`--auto` — вернуть автоматический расчёт);
- в обзоре клавиша `p` меняет питомца: тян → «ОС» (руководитель с фразами «Поторопись.»,
  «Что там по плотности??» — чем выше плотность, тем он довольнее) → щенок → котик → все сразу → без питомца;
- у каждого питомца свои фразы про плотность над ним; свои — в `~/.claude-squad/pet-phrases.json`
  (`{"cat": {"0": ["Где коммиты, кожаный?"]}}`, настроения 0…11), старый крупный портрет — `"pet_big": true`;
- питомец гуляет по низу обзора и рисуется силуэтом, без квадрата; `"pet_still": true` — стоять в углу;
- `"pet": "off"` — убрать, `"pet": "custom"` + `"pet_dir"` — свой рисунок: файлы `1.txt` … `12.txt`
- рядом показывается официальная плотность с t39: «· t39 9,2». Её Squad берёт из прежней строки
  статуса (сохранённой при `cs statusline --install`) или из `"t39_command"`, раз в 10 минут;
- мини-питомец с плотностью под полем ввода Claude: `cs statusline --install`
  (прежняя строка статуса сохраняется, `--uninstall` — вернуть);
  (от самого грустного), кадры анимации разделены строкой `---`.

## Дирижёр

Сессия, которая управляет остальными через `cs ctl list|read|send|answer|new|kill`.

**Что воркеры делают сами.** Воркеры, которых открывает `cs ctl new`, запускаются с
`--settings ~/.claude-squad/worker-settings.json`: коммит, push своей ветки, `git checkout -b` /
`git switch -c`, fetch/pull, status/diff/log и `rm -rf node_modules`/`dist`/`coverage` в своём worktree — без запроса разрешения. Force-push, push в
master/main, удаление веток и ссылок, `reset --hard`, `rebase`, `clean`, `rm` по-прежнему
спрашивают (в Claude Code «спросить» сильнее «разрешить»). Squad создаёт файл один раз; дальше
он твой — правь списки `allow`/`ask` как нужно, Squad его не перезапишет (сломанный JSON
воркерам не передаётся). Действует на новых воркеров; уже открытым — `cs ctl restart N`.

**Приложение «Оркестр»** — `~/Applications/Orchestra.app` (собирается само при обновлении). Окно с веб-интерфейсом;
Squad работает в фоне (`orchestra-start`, tmux-сессия `orchestra`), терминал можно закрывать. Подробнее — `contrib/macapp/README.md`.

**Веб-интерфейс — `cs web`.** Те же сессии, «ждут тебя» и живые терминалы в браузере; с телефона —
по ссылке с адресом Tailscale. Ключ в ссылке, не пересылай её. `"web_ui": "off"` — выключить.

**Ждут тебя — клавиша u.** Одним экраном все, кому нужен ты, по срочности, с командой разрешения
или вариантами меню. enter — открыть, i — написать сессии, d — ответить дирижёру, 1–9 — вариант
меню, y — разрешить запрос один раз.

**MR-обход и утренний отчёт.** Squad сам замечает MR воркеров и раз в 30 минут просит дирижёра
проверить их в GitLab (CI, замечания, влит). Сессию, у которой влиты все MR, предлагает закрыть.
В 9:00 (`"morning_brief_at"`, `"off"` — выключить) — короткий отчёт: уведомление на маке и
сообщение в «Избранное» через дирижёра. `cs ctl mr` — список MR и отметка их состояния.

**Разрешения, когда тебя нет у компьютера.** Запрос разрешения у воркера виден с командой:
«нужно разрешение · git push -u origin im/x» (в списке, в `cs ctl list`, в сводке дирижёру).
Подтверждаешь его только ты. Чтобы делать это с телефона, включи `"remote_control": true`:
воркеры, которых открывает Squad, запускаются с Remote Control под своим названием, и в
приложении Claude (claude.ai/code) видно сессию и её запрос. Уведомления на телефон —
в Claude Code `/config` → «Push when actions required». Для уже открытых сессий —
команда `/remote-control` в самой сессии или `"remoteControlAtStartup": true` в
`~/.claude/settings.json` (тогда — для всех сессий, с автоименами).

**Меню выбора у воркеров** (вопрос Claude с вариантами «1. … (Recommended) / 2. … / Type something»)
Squad видит отдельно: статус «меню · ждёт дирижёра», варианты — в сводке дирижёру и в `cs ctl list`.
Ответ — `cs ctl answer N 1|recommended|1,3|"свой текст"|submit|cancel` (`cs ctl send` в открытое меню
тоже отвечает). Варианты про push/merge/удаление/отправку — только с `--user-ok` после твоего «да».
Не ответил дирижёр за 10 минут (`"menu_auto_minutes"`, `-1` — никогда) — Squad выбирает рекомендованный
безопасный вариант сам, а рискованное меню отдаёт тебе с уведомлением. Воркеры, которых открывает
дирижёр (`cs ctl new`), запускаются без меню (`--disallowedTools AskUserQuestion`) и спрашивают текстом.
Файлы — `contrib/conductor` (роль, правила `rules.md`, QA-правила со скриншотами,
скиллы) и обёртки `contrib/wrappers`. Установка:
```bash
mkdir -p ~/.claude-squad/bin && cp -R contrib/conductor ~/.claude-squad/ && cp -R contrib/wrappers/* ~/.claude-squad/bin/
cs ctl new --dir ~/.claude-squad/conductor --title "Дирижёр" --conductor --color purple \
  --program ~/.claude-squad/bin/conductor/claude --prompt "Прочитай CLAUDE.md и rules.md, сделай cs ctl list и кратко скажи, что видишь."
```
Пути внутри `contrib/conductor` и обёрток — шаблоны (`/Users/USERNAME/...`); `install-mac.sh` (через `contrib/sq/localize`) подставляет твои.

## Помощник

Отдельная сессия для твоих вопросов («что происходит», «что с #5», «что дирижёр
делал без меня», «что взять дальше» — с учётом свободных сессий и лимитов (доска задач команды — через профиль); только тебе, никуда не пишет). Дирижёр в неё не пишет, сводки в неё не приходят, она не засыпает
и закреплена под дирижёром. Сам помощник пишет в другие сессии только по твоей
прямой просьбе.
```bash
cp -R contrib/assistant ~/.claude-squad/ && cp -R contrib/wrappers/assistant ~/.claude-squad/bin/
cs ctl new --dir ~/.claude-squad/assistant --title "Помощник" --assistant --color cyan \
  --program ~/.claude-squad/bin/assistant/claude
```
